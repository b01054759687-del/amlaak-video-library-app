# منظومة مكتبة الفيديوهات والتصاميم الهندسية — Amlaak Video Library

تطبيق ويب متكامل عالي الاعتمادية مبني على **Google Apps Script Web App** ومرتبط مباشرة بـ **Google Drive** و **Google Sheets** لإدارة، أرشفة، تتبع نسخ (Versioning)، وتصنيف فيديوهات مشاريع التشطيبات والمحتوى التسويقي ومخططات التصميم المعماري لشركة **أملاك ديزاين (Amlaak Design)**.

---

## 🎯 الأهداف المعمارية والقرارات الحاسمة المعتمدة

تم بناء المنظومة وفق متطلبات التشغيل والقرارات الهندسية المعتمدة التالية:

1. **القرار (A) — تصنيف الأعمال الهندسية (Work Category):**
   - حقل مستقل تماماً ومنفصل عن نوع الفراغ (`Space Type`).
   - يتضمن 15 تصنيفاً هندسياً معتمداً: `Roof, Ceiling, Materials, Furniture, Decoration, HDF, Ceramics, Electrical, Gypsum Board, Air Conditioning, Sound System, Doors, Windows, Painting, Plastering`.
   - يمثل بعداً تحليلياً أساسياً في الفلاتر ولوحة المؤشرات، ولا يُضاف افتراضياً إلى اسم الملف الفيزيائي.

2. **القرار (B) — تتبع نسخ مخططات التصميم (Design PDF Versioning):**
   - مخطط التصميم (PDF) يتبع الوحدة المعمارية (`Unit ID`) وليس فيديو فردي.
   - حفظ سجل النسخ الكامل (`Current` مقابل `Previous`) برقم نسخة متسلسل (`V01`, `V02`). رفع مخطط جديد لا يحذف ولا يستبدل الملف السابق على Google Drive نهائياً بل يقلب حالته إلى سابقة.

3. **القرار (C) — نشر تعديلات الوحدة وإعادة التسمية المجمعة (Batch Rename):**
   - تصحيح أي بيان رئيسي في سجل الوحدة (`Client Name`, `Location`, `Unit Type`, `Area`) ينتشر تلقائياً لجميع الصفوف المرتبطة به في شيت الفيديوهات والـ PDFs لمنع أي تباين في البيانات (Data Drift).
   - إذا نتج عن التعديل تغيير في صيغ أسماء الملفات الفيزيائية المعتمدة على Drive، تعرض المنظومة **شاشة مراجعة واعتماد إعادة التسمية المجمعة (Batch Rename Screen)** بجدول مقارنة بين الاسم الحالي والاسم المقترح، مع زر تأكيد موحد أو إلغاء للحفاظ على أسماء الملفات مع تحديث الميتاداتا فقط، وتوثيق كل ملف في سجل الأمان (`Audit Log`).

4. **شرط الصلاحيات المسبق على Drive (Editor Permission):**
   - التطبيق ينقل ويعيد تسمية الملف الأصلي نفسه (وليس إنشاء نسخة). يتطلب ذلك أن يمتلك حساب تشغيل التطبيق صلاحية **Editor** على الملف قبل تقديم الرابط، وإذا لم تكن متوفرة يُظهر النظام رسالة خطأ صريحة ومحددة.

5. **التعامل الواقعي مع Duration و Orientation:**
   - الحقلان يتم التعامل معهما على أنهما قد يكونان فارغين بشكل شائع دون تعطيل الحفظ أو الاعتماد عليهما في إحصائيات أساسية، ويتم استنتاج الـ Orientation فقط عند توفر العرض والارتفاع بشكل مؤكد.

## 📁 هيكل الكود والملفات

- `Code.gs`: موجه الويب ونقاط اتصال الـ API الآمنة (`google.script.run`).
- `Setup.gs`: دالة التهيئة التكرارية الذاتية (`setupSystem()`) لإنشاء الشيت والمجلدات دون تكرار.
- `Config.gs`: ثوابت النظام والتصنيفات ومستودع `ScriptProperties`.
- `Auth.gs`: منظومة التحقق من هوية المستخدم وصلاحياته ضد القائمة المعتمدة.
- `SheetRepository.gs`: طبقة التفاعل مع جداول البيانات والتحديثات المجمعة.
- `DriveService.gs`: طبقة التفاعل مع Google Drive (فحص الصلاحيات، إعادة التسمية، النقل، رفع الـ PDF، وإعادة التسمية المجمعة).
- `NamingService.gs`: محرك توليد أسماء الملفات القياسية المعتمدة وتنقيح الرموز.
- `Validators.gs`: التحقق الصارم من صحة المدخلات واستخراج معرفات Drive.
- `Utils.gs`: أدوات التنسيق، التواريخ، الترقيم المتسلسل، والأقفال (`LockService`).
- `AuditService.gs`: توثيق العمليات الحساسة في شيت `Audit Log`.
- `UnitService.gs`: إدارة الوحدات ونشر التعديلات وحساب إعادة التسمية المجمعة (القرار C).
- `VideoService.gs`: مسار الخطوات الـ 22 لتسجيل الفيديوهات وإدارة النسخ والفلاتر.
- `PdfService.gs`: رفع وتوثيق نسخ مخططات التصميم المعماري (القرار B).
- `DashboardService.gs`: حساب مؤشرات الأداء الفعلية والتوزيعات الهندسية.
- `Index.html`, `Styles.html`, `Client.html`: الواجهة التنفيذية بتصميم فاخر متناسق مع هوية أملاك ديزاين.
- `standalone-app.html`: تطبيق تفاعلي مستقل قابل للتشغيل الفوري في المتصفح محلياً مع محرك محاكاة كامل.
- `tests/unit-tests.js`: 18 اختبار وحدة مؤتمت تغطي التسمية، الفلاتر، وتوليد المعرفات.
- `tests/integration-simulation.js`: 5 اختبارات تكاملية تحاكي سيناريوهات الصلاحيات والنسخ ومعالجة الأخطاء الجزئية.

## 📋 ميثاق التسمية القياسية للملفات (Naming Rules §12)

- **فيديو المشاريع (Project Video):**
  `Client Name - Location - Project Video Type - Space Type - Shooting Date - Version Number.ext`
  *مثال:* `Ahmed Hassan - New Cairo - Final - Kitchen - 2026-08-17 - V02.mp4`
- **المحتوى التسويقي (Marketing Content):**
  `Content Type - Topic - Space Type - Shooting Date - Version Number.ext`
  *(نوع المحتوى التعليمي Educational يتم إخفاء نوع الفراغ منه تلقائياً)*
  *مثال:* `Educational - Plumbing Mistakes - 2026-08-17 - V01.mp4`
